# Дизайн-система

Актуальний стан: 2026-11-08. Основний напрям — ретро-телефони з характером. Нові моделі не додаються під час суто дизайн-проходу.

## Дві редакції, спільна взаємодія

| | Журнал | Сучасний |
| --- | --- | --- |
| Фон | Теплий папір / тепле чорнило | Прохолодний сіро-блакитний / графіт |
| Поверхні | Паперові панелі, тонкі лінії | Чіткі canvas / surface / soft / line |
| Геометрія | Невеликі прямі заокруглення | М’які заокруглення карток |
| Типографіка | Журнальна ієрархія | Segoe UI Variable / Segoe UI / system-ui |
| Акцент | Спільна мідна палітра | Та сама мідна палітра |

Редакція — `html[data-design="modern"]`, за відсутності атрибута — журнал. Тема незалежна: `data-theme="light"` / `"dark"`, без явного вибору — системна. Налаштування дизайну й теми зберігаються лише за чинною згодою; без неї зміна діє на поточній сторінці.

## Порядок CSS

`Layout.astro` імпортує стилі в такому порядку:

1. `global.css` — Tailwind, базова палітра, спільні компоненти й рух.
2. `editions.css` — основа перемикача редакцій та адаптації modern.
3. `modern.css` — графітові семантичні поверхні й повна neutral-палітра modern.
4. `concept.css` — спільний мідний акцент, узгодження журналу та порівняння.
5. `phone-detail.css` — галерея, ритм історії, характеристики й зразки кольорів.

Назви `orange-*` лишилися сумісними токенами Tailwind; фактичний інтерфейсний відтінок — мідний. Знак бренду має власний колір. Не підміняйте кольори окремими `dark:`-класами.

Акцент для тексту на світлому фоні — `#994320`, на темному — `#e4a17a`. Основна кнопка — `#97431f` із білим текстом. Для перевірених основних пар контраст 5.59:1–7.65:1; це не повний аудит усіх кольорів і станів.

## Сторінка телефону

- Над колонками — Фото / Історія / Відео / Технічний портрет. Відеопосилання показується лише за наявності ролика. На мобільному навігація в одному рядку й враховує ховання хедера.
- Ліворуч — галерея та кольори корпуса. На високому desktop-вікні вона sticky; нижче 800px висоти — звичайний потік, щоб довгі підписи й кольори залишалися доступними.
- Лічильник, кнопки 44px, мініатюри, клавіатура, свайп і повноекранний перегляд працюють з одним активним кадром. Підпис та авторство змінюються разом із ним. Перше фото завантажується одразу, наступні — lazy.
- Праворуч — історія, **широкий відеоблок**, характеристики. Відео під лівою галереєю відхилено користувачем через малий плеєр; не повертати таке компонування.
- Історія має обмежену довжину рядка, спільні інтервали абзаців, підзаголовків, списків і джерел. Modern використовує окрему поверхню з padding. Не додавайте назад блок «Чим запам’ятався» чи друге відео.
- Таблиця використовує канонічні поля `lib/specs.ts`, явний colgroup близько 33/67% та перенесення довгих значень. `specVariant` показує відмінності N93i, N95 8GB, N81 8GB в одній таблиці. Нове поле варіанта потребує підтримки схеми.

### Кольори корпуса

`src/lib/phone-colors.ts` повертає орієнтовний CSS-зразок за назвою; наявні 179 різних назв/аліасів трьома мовами покрито. Оригінальний текст залишається видимим, зразок декоративний (`aria-hidden`). Непізнана назва лишається текстом. Це не перемикач фото, не виміряний колір виробника й не точний Pantone. Блок має локалізований підпис «Відтінки орієнтовні».

## Порівняння, бренди й головна

Порівняння пояснює форму, задум і можливості, без балів та переможця. «Його характер» береться з milestone моделі. «—» означає непідтверджене значення, а не автоматично відсутню функцію. Пошук, swap, фільтр відмінностей, reset і URL-синхронізація лишаються доступними в обох стилях.

Картки «Характер у різні роки» у `BrandMilestones.astro` мають padding 20px / 24px від 640px. Текст не повинен торкатися країв; рік, назва й опис мають власні проміжки.

Головна: обкладинка RAZR V3, чотири недавні поповнення за `dateAdded`, тематичні добірки, порівняння та принципи проєкту. Дата додавання не підмінює рік випуску. `/updates/` містить лише завершені зміни; історичні дати відновлені з Git, без вигаданих проміжних днів.

## Рух і контроль якості

- Декоративний hover — лише `(hover:hover) and (pointer:fine)` / `hover-desktop:`.
- Єдині `--motion-ui`, `--motion-image`, `--motion-enter`, `--motion-easing`; повага до `prefers-reduced-motion`.
- Контент залишається видимим без JavaScript; прокручування не повинно робити текст недоступним.
- Перевіряйте desktop та 390px, обидві редакції й теми, Tab/Escape, світлі кольори, довгі назви та характеристики, варіанти й відсутні фото/відео.
- Перевірки збірки: `npm run build`, потім `npm run audit:seo`; для контенту — `npm run audit:locales`.

Останній UI-прохід: N93/N93i, N95 8GB, N81 8GB, Pixel 6, iPhone 12 і Google. Це вибіркова перевірка інтерфейсу, а не сертифікація кожної моделі чи фізичного пристрою.
