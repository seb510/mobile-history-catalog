# Nokia N95 8GB

N95 8GB is documented as a variant section on the existing N95 page, with one gallery image and variant values integrated into the shared Technical portrait table. It has no independent catalog record or comparison slot. The section describes the international 2007 WCDMA 2100 version, not the later American model. Base N95 specifications remain unchanged; specVariant stores only confirmed differences. Shared rows render once, differing rows label N95 and N95 8GB.

- [Nokia shipping announcement, 15 October 2007](https://www.globenewswire.com/news-release/2007/10/15/1848830/0/en/Ship-Me-says-the-Nokia-N95-8GB.html): release, black body, display, multimedia storage and key capabilities.
- [Nokia archived specifications](https://web.archive.org/web/20071016071744/http://www.nseries.com/nseries/v3/media/sections/products/tech_specs/en-R1/tech_specs_n95_8gb_en_R1.html): battery, dimensions, weight, display, camera, connectivity and software platform.
- [American release, January 2008](https://www.globenewswire.com/news-release/2008/01/07/1848759/0/en/New-Nokia-N95-8GB-brings-the-best-in-portable-entertainment-to-US-consumers.html): region distinction.

Nokia’s listed 100 MB application/personal-data memory is not used as a RAM figure. RAM and chipset are omitted pending an accessible primary developer specification; the old Forum Nokia archive did not load during this pass. No launch price is converted from EUR into an invented USD figure.
