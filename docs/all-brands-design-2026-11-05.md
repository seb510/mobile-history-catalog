# Усі сторінки брендів і ховер — 2026-11-05

## Композиція

Спільний layout охоплює 9 брендів × 3 локалі. Спочатку — логотип, назва, заснування/країна/лічильник і текст виробника. Фото-обкладинок і «З чого почати» немає.

На desktop текст і блок «У нашому архіві» утворюють дві колонки, замінюючи порожній правий простір змістом: характер добірки, динамічні роки, форми корпусів, посилання на моделі та каталог із brand/form. Факти header розтягуються на всю доступну ширину. На mobile блоки йдуть послідовно. Лічильник показаний один раз у header.

Для 7 брендів із кількома телефонами BrandMilestones рендерить куровані епізоди та порівняння. Siemens зберігає свою пару A65/SXG75. HTC й Huawei мають по одному запису: без хронології та самопорівняння, одна горизонтальна картка на desktop. При двох моделях колекція має дві колонки. Усі колекції збережені; 89 моделей, жодних нових записів чи фото в цьому проході.

Компоненти: BrandDetail.astro, BrandMilestones.astro; редакційні маршрути й локалізовані тексти — brand-editorial.ts. SiemensBrandStory.astro видалений як замінений загальним компонентом. Старий markdown брендів і його fallback не змінені.

## Ховер

Видалено правило .editorial-card:hover .card-copy з фоновою заливкою. Замість нього змінюються рамка та колір card-title, без підйому/масштабування. Тільки fine pointer + hover; переходи використовують motion-ui. Виправлення спільне для індексу брендів, карток телефонів і пари на головній.

## Перевірка

- Реальне наведення Motorola й Nokia 3250 головної: :hover=true, card-copy background rgba(0,0,0,0).
- Google: desktop світла й темна теми. Формат логотипів лишається білим незалежно від теми.
- Motorola en 320 px: clientWidth/scrollWidth 305/305, 11 моделей.
- HTC: одна картка, без timeline/self-compare.
- Google → «Моноблок»: каталог brand=Google&form=candybar, 4 видимі картки.
- Перевірені всі 27 HTML сторінок: наявні overview/aside, точна кількість карток, відсутність cover/start та умовна хронологія.
- Astro check: 0 errors / 0 warnings (3 hints); build: 324 сторінки. SEO audit passed, 185 canonical URLs, indexing disabled. git diff --check clean.
