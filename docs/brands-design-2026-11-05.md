## Результат

Індекс із 9 брендів отримав короткі редакційні описи, роки моделей архіву, динамічні лічильники й рівні картки. Desktop — 3 колонки, tablet — 2, mobile — 1 горизонтальна картка в рядку. Логотипи збережені на білих плашках.

Siemens — перша сторінка нового формату: SK65 на обкладинці, три стартові моделі, чотири поворотні моменти досвіду, готове порівняння A65 / SXG75, історія виробника в розгортному блоці та всі 14 моделей за роками. Дані інших detail-сторінок не перебудовані. Загалом 89 телефонів, нових моделей не додано.

- src/components/BrandDetail.astro — підключення композиції Siemens; інші бренди мають попередню подачу; попередній Content збережений.
- Три src/pages/**/brands/index.astro використовують спільний локалізований вступ також для SEO description.

Жодного нового JS. Історичні епізоди посилаються на існуючі перевірені записи телефонів; діапазон років індексу позначає представлені моделі, а не тривалість існування виробника. Фото не змінювалися; CSS збільшення SK65 прибирає візуальну втрату масштабу через прозорі поля джерела, весь телефон лишається видимим.
