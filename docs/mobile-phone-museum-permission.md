# Mobile Phone Museum: permission and attribution

On 31 October 2026 the project owner reported contacting Mobile Phone Museum and receiving permission to use their photographs in this noncommercial catalog. The owner stated the conditions: retain the museum credit, display the source, and link to the museum website so visitors can find the original. This record documents the owner's report; it is not a copy of the museum correspondence and does not claim an independently reviewed license agreement.

Required visible credit: **Фото: Mobile Phone Museum** (English: **Photo: Mobile Phone Museum**). On detail/gallery views the label also includes **mobilephonemuseum.com**. Link each credit to the original model page on `https://www.mobilephonemuseum.com/`; external links use a new tab with `noopener noreferrer`.

These are permission-based assets, **not Creative Commons or public-domain files**. Conversion to WebP does not grant an open license or remove the credit requirement. The site does not grant downstream users permission to reuse the museum's photographs. Do not invent additional permission terms, exclusivity, unlimited redistribution or AI-editing rights.

## CX65 and CX75: availability checked

The direct `/phone-detail/cx75` URL returned HTTP 404. The museum's own visible search interface returned **0 results for "CX75"**. No museum photographs were available from those results, so existing local Commons images and their correct credits remain in use for these two records. Do not download the museum's placeholder as a phone image, substitute a similar model or relabel Commons photos as museum work.
