## Порівняння: швидкий вибір — 30 жовтня 2026

Під порожнім пошуком показуються швидкі моделі та кнопки брендів (uk/ru/en). Другий слот пропонує найближчі за роком моделі того самого бренду й виключає вже вибрану. Готові пари змінюють React-стан без перезавантаження. Початкове читання URL більше не затирається ефектом синхронізації; однакова модель в обох слотах відхиляється. Enter вибирає перший результат, ArrowDown переводить фокус до результатів, Escape очищає запит; aria-controls заданий лише для наявного списку.

Браузерна перевірка перед цим завершенням: швидкий вибір N8, пошук Google через кнопку бренду, вибір Pixel 9, збереження пари після reload і готова пара 3210/3310. Мобільну композицію переглянуто; результати пошуку розташовані в потоці. Фінальні клавіатурні обробники додано після браузерної перевірки, окремо в браузері ще не перевірено. Системний npm зараз не знаходить Node >=22.12; перевірку типів і збірку запущено безпосередньо через вбудований Node 24.22.1, без зміни системної конфігурації.

## Технічне SEO перед публікацією

Реалізовано метадані uk/ru/en, коректні canonical/hreflang з урахуванням фактичних перекладів, статичні sitemap/robots, JSON-LD WebSite/WebPage/CollectionPage/AboutPage і BreadcrumbList. Додані посилання на близькі моделі того самого бренду та парні порівняння. Немає вигаданих Offer/Review/рейтингів або дат оновлення. Індексація вимкнена за замовчуванням; production потребує SITE_URL та SEO_INDEXABLE=true. Інструкція — [seo.md](seo.md).

`npm run build` і `npm run audit:seo` пройшли для локального режиму та окремої контрольної збірки з індексацією на seo-validation.example.org (нічого не публікувалося). 252 HTML-сторінки, 117 канонічних адрес у sitemap. Перевірено метадані, єдиний H1, парсинг JSON-LD, відсутність дубльованих заголовків у sitemap, canonical-цілі й взаємність hreflang, виключення 404 і robots у двох режимах. Для типізації серверної конфігурації додано dev-залежність @types/node. Підказка про Zod `.url()` існувала раніше. Після перевірки збірку повернено в локальний режим.

Не перевірено зовнішні Google Rich Results/Search Console та польові Core Web Vitals: для цього потрібний публічний домен. Візуальний браузерний аудит нових посилань у цьому проході не виконувався. Деплой й push не виконувалися.
