# Siemens M55 — джерела та медіа

Додано 9 листопада 2026; один slug `siemens-m55`, uk/ru/en. Рік 2003, Dynamic Light, X-подібна клавіатура, Cubasis mobile, опційна QuickPic IQP-500 замість вбудованої камери. Не змішувати з M65 чи S55.

## Дані

- [Повідомлення Siemens до CeBIT 2003 у GSMOnline, 10.03.2003](https://gsmonline.pl/artykuly/szczegoly-techniczne-telefonu-siemens-m55): 4096 кольорів, 101×80, GSM 900/1800/1900, GPRS Class 8, MIDP 1.0, Cubasis, кабель/Data Suite, габарити, вага, акумулятор.
- [Інструкція Siemens, с. 98 та 124](https://www.instructionsmanuals.com/sites/default/files/2019-05/Siemens-M55-es.pdf): 83 г, 101×46×21 мм, 700 мА·год; камера IQP-500 як аксесуар, VGA 640×480 і спалах.
- [Інструкція Dynamic Light](https://siemens.manymanuals.pl/mobile-phones/be-inspired-m55/users-guide-33286/39): бічні LED, ритми для дзвінків/повідомлень/будильника, деморежим.
- Пам’ять у вторинних довідниках різниться (1.2/1.6/2 MB). Числове storageMb, RAM та чипсет не вигадували; непідтверджені поля пропущено.
