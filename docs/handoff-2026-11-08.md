# Продовження роботи — 8 листопада 2026

## Перші кроки на іншому комп’ютері

1. Перенесіть актуальні зміни через Git або копію робочих файлів. На момент передачі цього проходу агент не робив commit/push/deploy; новий `src/styles/liquid-glass.css` також потрібно включити в перенесення. `git status --short` — джерело фактичного стану.
2. Встановіть Node.js 24 (див. `.node-version`), виконайте `npm ci`.
3. `npm run dev -- --background`; адресу й порт прочитайте з виводу. Керування: `npm run astro -- dev status`, `npm run astro -- dev logs`, `npm run astro -- dev stop`.
4. `npm run build` виконує перевірку типів і SSG; додатково `npm run audit:locales`, `npm run audit:seo` після build.
5. Прочитайте `AGENTS.md`, цей документ і `docs/design-system.md`. Старі датовані записи — історія, а не поточні вимоги.

Для телефона в одній Wi-Fi мережі: `npm run dev -- --force --host 0.0.0.0 --background`. IP залежить від нового комп’ютера. Не переносіть старі IP/PID, node_modules, dist, .astro, tmp чи локальні .env. Параметри середовища передавайте окремо; локальна індексація вимкнена. Push і deploy робить лише власник, commit — за прямим запитом.

## Що завершено

- Modern став скляною редакцією: льодяно-блакитна світла й графітова темна палітра, бірюзові акценти (#087F8C light / #67D9DF dark), суцільні кнопки #087783 з білим текстом. Журнал зберігає мідь.
- Плаваючий хедер, скляні меню/пошук/панелі/картки на всіх типах сторінок. Blur: контент 20px, мобільний 12px; навігація 32px, мобільна 24px. Тіні мінімальні, об’єм переважно через грань і blur. Reduced transparency/contrast вимикають фільтри, reduced motion — рух.
- Hover лише мишкою: крайовий відблиск і невеликий підйом. Мобільне меню без порядкових номерів, легкі рядки; лічильник «Мої телефони» збережено.
- Футер відокремлений від країв, назва бренду явно світла на темному фоні.
- Оригінальний знак: ретро-кнопковий телефон у сучасній графітовій плашці з мідним екраном. Синхронні LogoMark, favicon.svg, PlaceholderArt і React PlaceholderIcon. Перегенеровані favicon-32.png, apple-touch-icon.png, og-image.png. Після зміни знака — `npm run gen:images`.
- Галерея: fullscreen і zoom замінені іконками з локалізованими aria-label/title, лупа +/−; плавна поява кадрів і відкриття/закриття fullscreen, збережені стрілки/свайп/клавіатура/captions/credits. Zoom не приписує інший опис фото.
- Порівняння: прибрано порожню смугу перед заголовком (`overflow:clip`, без backdrop-filter на контейнері таблиці). Sticky назви моделей збережені; фактичний відступ від хедера вимірюється ResizeObserver, перемикання редакції та resize його оновлюють; при прихованому хедері top=0. Щільний фон і межа відділяють заголовки від рядків в обох редакціях.
- Samsung: замість Galaxy S — архівний SGH-сигнал, точна модель у джерелі не зазначена. Apple — опційний сигнал iPhone 14+, Google Super G — запуск/перше налаштування, не гарантія кожного reboot. Джерела й хеші: docs/audio-implementation.md і startup-audio-sources-2026-11-08.json.

## Де змінювати

Порядок CSS: global → editions → modern → concept → phone-detail → liquid-glass. Останній файл обмежено `data-design="modern"`; спільна галерея й sticky — також global.css. Сумісні orange-* токени в modern тепер бірюзові. Не повертайте помаранчеві hardcoded кольори для UI modern.

Header.astro — меню; Footer.astro — бренд/структура; PhoneDetail.astro + scripts/phone-gallery.ts — галерея; CompareIsland.tsx — вимірювання sticky; scripts/catalog-position.ts враховує верхню позицію плаваючого хедера. AboutPage/PrivacyPage мають спільні glass-surface панелі.

## Перевірки й наступна робота

Виконано в браузері: сучасні світла/темна головна, мобільне меню (393×852), темний мобільний каталог, футер, пошук, fullscreen/zoom/закриття галереї, таблиця порівняння без верхньої порожньої смуги та sticky при скролі. Ширина 1024 лишає desktop-навігацію. Остання збірка: 441 HTML; актуальні фінальні результати перевірок зазначені у відповіді агента. Немає окремої тестової системи.

На іншому комп’ютері повторіть: дві редакції × дві теми, мобільне меню й клавіатура, sticky при скролі вниз/вгору, галерея +/−/Escape/швидкі перемикання. Фізична продуктивність великої кількості blur на слабкому телефоні ще потребує перевірки; емулятор не замінює цього. Скриншоти в tmp — локальні докази, не залежність проєкту.

Стрічка під хедером (заміна погоди на дату оновлень) лише обговорювалась — не реалізована. Нових моделей у цьому проході не додавали. Відео під лівою галереєю, другий ролик і «Чим запам’ятався» не повертати.
