# SEO-аудит — 30 жовтня 2026

Оновлення після редакційного проходу: суфікси title скорочено, заголовків понад 80 символів — 0 замість 13; тексти дев’яти моделей доповнено в 13 мовних записах, посилання в uk-тексті є у 25/69 моделей замість 21/69. Нижче збережений початковий зріз аудиту; деталі змін — `quality-audit.md`.

Перевірено поточний код та наявний `dist`; нову збірку в цьому аудиті не запускали. `node scripts/audit-seo.mjs` через вбудований Node 24.22.1 проходить: 252 HTML, 117 canonical URL, індексація вимкнена. Перевірка не вимірює позиції Google, зовнішні rich results чи польову швидкодію.

## Працює

Унікальні title та description серед 117 URL sitemap, один H1, canonical без query, взаємні hreflang для справжніх перекладів, виключення fallback-дублів/404 з sitemap. JSON-LD синтаксично коректний. Фото мають fallback, є посилання на бренди, каталог, споріднені моделі та порівняння.

## Пріоритети

1. **Публікація:** домен ще `mobile-history.example`, robots містить Disallow, HTML — noindex. Це очікувано локально; публічна збірка потребує правильного SITE_URL та SEO_INDEXABLE=true, перевірки HTTP-кодів, HTTPS/host і Search Console.
2. **Preview:** наявне поєднання Disallow / та noindex не гарантує виключення URL із Google: заборона сканування приховує noindex від робота. Для доступного публічного preview потрібен crawlable noindex або автентифікація. Під час цього аналізу поведінку не змінювали.
3. **Джерела:** із 69 українських записів лише 21 має зовнішнє Markdown-посилання в основному тексті (кредити фото не враховані). Це інвентаризація наявності посилань, а не підтвердження якості джерел. Решту 48 варто перевіряти й доповнювати першоджерелами перед заявою про повну перевіреність каталогу.
4. **Переклади:** 69 uk, 11 ru, 11 en. Для 58 моделей немає окремого ru/en контенту. Fallback коректно канонізується, але не дає повноцінного англомовного/російськомовного охоплення.
5. **Редакційна цінність:** 61 з 91 канонічної мовної сторінки телефону має менш як 100 слів у прозовому блоці (без таблиць, навігації й схожих моделей; приблизний HTML-підрахунок). Це не помилка SEO і не мінімум Google. Варто додавати конкретні факти, вплив моделі, контекст конкурентів, відмінності версій — коли це допомагає читачу, без наповнення заради обсягу.
6. **Заголовки:** 13 canonical title довші за 80 символів. Це евристика для редакційної перевірки, не ліміт Google. Для довгих назв можна скоротити повторюваний суфікс. Description у частини моделей — короткий milestone; доречно додати конкретні відомості, не однаковий шаблон.
7. **Межі автоматичного аудиту:** JSON.parse не перевіряє відповідність Schema.org/вимогам Google. Аудит також не підтверджує реальні HTTP-редиректи/404, robots заголовки CDN, швидкість чи доступність зовнішніх фото. Два записи без фото: SK65, SGH-E700. Попередні HTTP 429 Commons не є доказом зламаних URL.

Найкращий наступний порядок: уточнити preview-режим і розширити SEO-перевірки → коротші заголовки там, де потрібно → джерела й історії найважливіших моделей → повні переклади → вимірювання після публікації. Деплой і push не виконувалися.
