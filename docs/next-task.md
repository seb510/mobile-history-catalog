# Наступна задача

## Дослідити прогалини технічних полів Nokia/Siemens

Звіт `node scripts/audit-phone-data.mjs` → [docs/nokia-siemens-inventory.md](nokia-siemens-inventory.md)
показує 76 моделей Nokia та Siemens із порожніми технічними полями (chipset, ramMb, storage,
storageExpandable, camera.rear/front, battery.type, connectivity, simType тощо) — свідомо не
заповненими, бо на момент додавання не було підтвердженого джерела.

Це дослідницька, а не механічна задача: для кожної моделі потрібен первинний документ
(інструкція виробника, офіційний data sheet, пресреліз) чи щонайменше два незалежні узгоджені
джерела — не Wikipedia як єдине джерело і не здогадка за аналогією з іншою моделлю тієї самої
лінійки. Підтверджену відсутність функції (наприклад, немає фронтальної камери) позначати текстом
у записі, а не залишати порожнім полем, якщо це дійсно встановлено. Непідтверджене лишати
порожнім і далі — не вигадувати.

Через обсяг (76 моделей) має сенс братися частинами: обрати кілька моделей за раз (наприклад,
по бренду чи по десятиліттю), а не намагатися закрити все одразу.
