## Варіант N81 8GB

Один запис N81 із specVariant. Відмінності лише в наявних рядках пам’яті й карти пам’яті. Масовий накопичувач номіналом 8 ГБ не дорівнює RAM чи гарантованому вільному простору. Модель не додається вдруге в каталог.

Першоджерела: [Nokia, обидві версії у продажу, 22.10.2007](https://www.globenewswire.com/news-release/2007/10/22/1848848/0/en/bored-never-again-nokia-n81-8gb-now-shipping.html), [Nokia RM-223 user guide](https://fcc.report/FCC-ID/OW3RM-223/829248.pdf), [Nokia RM-179 N81 8GB user guide](https://i.smartphone.ua/docs/instr/instr_nokia-n81-8gb_eng.pdf).

Виправлено відсутність FM: інструкції описують FM/Visual Radio та дротову гарнітуру як антену. UMTS уточнено як 2100 МГц, не всі чотири GSM-діапазони. Решта старих характеристик поза цим проходом; невпевнені старі CPU/доступна пам’ять потребують окремого фактчекінгу.
