# Продовження роботи — 16 листопада 2026

## Перші кроки на іншому комп’ютері

1. Перенести робочі файли через Git або копією проєкту. Поточні незакомічені зміни включають попередні зміни Modern-карток/кабінету/хедера, наведені нижче правки головної й брендової сторінки, документацію та кнопку еволюції. `git status --short` — джерело фактичного стану.
2. Встановити Node.js 24 (`.node-version`) і виконати `npm ci`.
3. Запустити `npm run dev -- --background`; порт прочитати з виводу. Керування: `npm run astro -- dev status`, `npm run astro -- dev logs`, `npm run astro -- dev stop`.
4. `npm run build` перевірено 2026-11-16: Astro check завершився з 0 помилок і 0 warnings (5 hints), зібрано 591 сторінку. Locale audit окремо не запускався; за потреби — `npm run audit:locales`.
5. Прочитати `AGENTS.md`, цей файл і `docs/design-system.md`. Старі звіти нижче — історія, а не черга поточних робіт.

Push і deploy виконує власник; commit робити лише за прямим запитом. Не переносити `node_modules`, `dist`, `.astro`, тимчасові файли чи локальні `.env`.

## Кнопки еволюції

Кнопки на головній і сторінках брендів відкривають відповідні діалоги еволюції. Їхній спільний клас `evolution-trigger` визначено в `src/styles/global.css`; піктограма повноекранного відкриття — `src/components/EvolutionIcon.astro`. В обох редакціях використовується заливка акцентним кольором: мідь у журналі, бірюзовий у modern. Колір тексту modern прив’язаний до нейтрального токена, щоб зберегти контраст у світлій і темній темах. Не замінювати піктограму стрілкою-посилання.

## Modern-палітра — 16 листопада 2026

Modern використовує сланцево-графітову основу з ролями бірюзи (дії), синього (навігація), коралового (медіа/порівняння) й золота (історичні маркери). Карткова система розгорнута для всіх основних маршрутів: спільні поверхні й тіні, різні силуети для моделей, брендів, ОС та інформаційних блоків. Плаваючий хедер і каскадний `scroll-reveal.ts` лишаються Modern-only; рух поважає `prefers-reduced-motion`. Перевірено синтаксис компонентів після останніх змін збіркою; деталі — у `docs/design-system.md`.

Картки телефону Modern тепер мають бренд-мітку, модель-заголовок, видимий бейдж року й окремий блок короткого опису без мінімальної порожньої висоти під короткими назвами. На мобільному тематичні картки головної та порівняння стають горизонтальними без обрізання опису. Кабінет стилізовано в обох редакціях: огляд, акаунт, хронологія та телефони отримали послідовну ієрархію з урахуванням паперової журнальної теми. Закладка-кнопка стала менша візуально, зміщена від краю й має зрозумілий знак додавання; Modern-шапку пом’якшено, її active hover та індикатор кабінету приглушено.

Останній візуальний прохід: обкладинка Siemens SK65 на головній отримала контрастні кольори тексту відповідно до світлої/темної теми; картки порівняння поколінь розділені проміжками й мають власні межі, щоб лінії стику не проходили крізь композицію. На сторінках брендів, зокрема Alcatel з однією моделлю, архівний блок показує часовий діапазон, модель і форм-фактори поруч із текстом історії. Ці правила scoped на Modern; журнальна редакція зберігає свою композицію.
