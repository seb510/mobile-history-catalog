# Продовження роботи — 16 листопада 2026

## Перші кроки на іншому комп’ютері

1. Перенести робочі файли через Git або копією проєкту. Поточні незакомічені зміни включають спільне оформлення кнопок «Еволюція телефонів» / «Еволюція бренду» та цей handoff. `git status --short` — джерело фактичного стану.
2. Встановити Node.js 24 (`.node-version`) і виконати `npm ci`.
3. Запустити `npm run dev -- --background`; порт прочитати з виводу. Керування: `npm run astro -- dev status`, `npm run astro -- dev logs`, `npm run astro -- dev stop`.
4. Для перевірки змін контенту виконати `npm run astro check` або `npm run build`; `npm run audit:locales` перевіряє локалізовані записи. Після цього проходу збірку й аудити не запускали.
5. Прочитати `AGENTS.md`, цей файл і `docs/design-system.md`. Старі звіти нижче — історія, а не черга поточних робіт.

Push і deploy виконує власник; commit робити лише за прямим запитом. Не переносити `node_modules`, `dist`, `.astro`, тимчасові файли чи локальні `.env`.

## Кнопки еволюції

Кнопки на головній і сторінках брендів відкривають відповідні діалоги еволюції. Їхній спільний клас `evolution-trigger` визначено в `src/styles/global.css`; піктограма повноекранного відкриття — `src/components/EvolutionIcon.astro`. В обох редакціях використовується заливка акцентним кольором: мідь у журналі, фіолетовий у modern. Колір тексту modern прив’язаний до нейтрального токена, щоб зберегти контраст у світлій і темній темах. Не замінювати піктограму стрілкою-посилання.
