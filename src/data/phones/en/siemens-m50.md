Shown at CeBIT in 2002, the M50 was the first Siemens phone able to run Java applications (MIDP 1.0). In practical terms, this meant downloading games and small utilities separately rather than relying only on software installed by the manufacturer. That was a notable addition for a mass-market phone.

Replaceable CLIPit colour covers and out-of-the-box Cyrillic support made it a recognisable and convenient choice in post-Soviet markets.

Source: [Siemens C45 / M50 / MT50 service documentation, 05/2002, Flash Memory section](https://www.mobilgyujtemeny.hu/letolt/Service%20manual/Siemens/siemens_c45_m50_mt50_servicemanual_en.pdf).
The documented 48 Mbit of flash also included software. It should not be treated as 6 MB of user-available storage, so no numerical storage figure is shown. A launch price in dollars is also unconfirmed.
