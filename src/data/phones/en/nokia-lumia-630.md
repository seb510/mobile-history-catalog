The Lumia 630 put Windows Phone 8.1 in a simpler body with a replaceable rear shell. On-screen navigation removed the need for a separate row of capacitive keys.

Action Center opened with a swipe from the top and grouped notifications with quick settings. That changed daily use more than the handset’s visual differences from earlier affordable Lumia models.
