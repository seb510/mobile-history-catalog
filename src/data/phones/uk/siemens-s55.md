S55 застав мобільну фотографію ще в підлітковому віці: власної камери в корпусі не було, але в
комплекті постачався зйомний модуль QuickPic IQP-500, який приєднувався знизу й знімав кадри
640×480 із власним ксеноновим спалахом — рідкість навіть для флагманів того часу.

Поряд із модульною камерою S55 ніс кольоровий екран, Bluetooth і підтримку Java — набір, що
ставив його в один ряд із Sony Ericsson T68i як один із найтехнологічніших телефонів 2002 року.
Для Siemens це була заявка на статус інноватора, а не просто виробника надійних «робочих коней».
