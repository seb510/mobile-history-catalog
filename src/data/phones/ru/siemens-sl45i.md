SL45i продолжил идею семейства SL45: музыку можно было носить вместе с телефоном на сменной MultiMediaCard, а слушать — через встроенный MP3-плеер. Для начала 2000-х это был отдельный сценарий использования, а не просто ещё один пункт в списке функций.

Буква «i» обозначала обновление программной платформы с поддержкой Java.
